# YouTube RAG Chatbot

## Features

- YouTube Transcript API
- HuggingFace Embeddings
- FAISS Vector Store
- LangChain
- Groq Llama 3.3
- Completely Free

## Installation

```bash
python -m venv myvenv
```

Activate

Windows

```bash
myvenv\Scripts\activate
```

Install packages

```bash
python -m pip install -r requirements.txt
```

Create

```
.env
```

Add

```
GROQ_API_KEY=YOUR_KEY
```

Run

```bash
python app.py
```
